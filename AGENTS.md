# Agent instructions

This installer moved into dotfiles. Read the
[current README](https://github.com/colonelpanic8/dotfiles/blob/master/nixos/family-installer/README.md)
and [current AGENTS.md](https://github.com/colonelpanic8/dotfiles/blob/master/nixos/family-installer/AGENTS.md)
before assisting with USB creation, installation, support, or updates.

Use dotfiles' `family-stable` branch and its `nixos/family-installer` flake for
new media. This repository retains the earlier implementation for history.
Do not make installer changes or register new machines here.

Confirm the exact destination device before any destructive write. Writing an
ISO erases the selected USB. Installing NixOS can erase the computer's disk.
Never copy Ivan's private credentials or personal sync data to a family machine.
